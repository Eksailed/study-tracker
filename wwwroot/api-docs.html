Как войти

Токен выпускается в разделе «Доступ к API» в приложении и показывается один раз. Передавайте его в заголовке Authorization. Токен работает только на адресах /api/v1.

curl -H "Authorization: Bearer zt_…" /api/v1/subjects

Группы

Токен видит и меняет только личные предметы и задания. Группы, задания группы и личные отметки по ним доступны только в приложении: адрес /api/assignments/{id}/progress с токеном не работает.

Если передать groupId в запросе с токеном, ответ будет 400. В ответах токену поле groupId всегда null.
