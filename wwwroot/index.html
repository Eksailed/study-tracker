      Календарь

      Сроки невыполненных заданий в календаре телефона или компьютера. Календарь только читает ленту и ничего не записывает в «Зачёт».

      Загружаем…

      Ссылка готова

      Ссылка показывается один раз. Скопируй её и вставь в календарь как подписку по адресу. Потеряешь — перевыпусти: старая перестанет работать.

      Google Календарь: «Другие календари» → «Добавить по URL». Apple Календарь: «Файл» → «Новая подписка на календарь». Outlook: «Добавить календарь» → «Подписаться из Интернета». Чтобы лента открылась из интернета, «Зачёт» должен быть доступен снаружи по HTTPS. Не показывай ссылку другим людям: по ней видны твои задания.

      Старая ссылка перестанет работать, календари с ней перестанут обновляться. Перевыпустить?
